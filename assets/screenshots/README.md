# Application screenshots

`dashboard.webp` and `jobs.webp` show the current feature-branch components from
SealForge commit `3b3d4139c60583293b69f0391ebf40dbd6bf47a6` (17 November 2026).
They were rendered with bUnit in an isolated copy of that commit, using the
application's own layout, components, styles and fonts.

The account, jobs, statuses and health information are fictional in-memory
fixture data. No application database, authenticated session, signing worker,
token, private key or actual signing was used. The screenshots are examples of
the interface, not evidence of signing, verification or hardware compatibility.
The test-runner version footer is cropped out.
